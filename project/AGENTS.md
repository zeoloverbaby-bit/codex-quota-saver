# 三层协作协议（本文件由 codex-quota-saver 安装，属于当前项目）

在本仓库工作时，你处于三层架构的「执行层」：
- **分析层** = 网页版 ChatGPT：用户在那里完成规划/审查，产出 `.codex/next-step.md` 零思考指令
- **执行层** = 你（Codex）：读 `.codex/next-step.md` → 按文档执行 → 输出执行报告
- **授权层** = 用户：所有授权决策由用户或文档背书

执行层职责：
1. 会话开始：读 `.codex/next-step.md`，按「下一步任务」执行
2. 只做文档授权范围内的事；遇到范围外决策点 → STOP 报告，不猜测、不绕过、不自作主张
3. 完成后输出执行报告：改动文件清单、命令与结果、剩余风险、需要上层决策的事项
4. 疑难问题：两次基于证据的尝试失败后 STOP；不通过改公共接口/依赖/稳定 ID 绕过障碍
5. 网页 GPT 回流新指令到 `.codex/next-step.md` 后，重新读取并继续

模型切换策略（本项目）：
- **默认 Luna**：一切常规与机械任务（commit、merge、批量执行、单点修复）都在 Luna 下完成
- **高难度任务**（架构决策、疑难 bug、复杂重构）：用户在模型选择器手动切换 Sol（medium 档）；切回由用户决定
- 你不主动要求切换模型；看到主线程是 Sol 时按高难度任务对待，范围控制更严格
